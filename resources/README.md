# resources/

This folder holds image assets copied in by the "Resource Management"
feature (see the main README) when a design references an image.

The sample project archive this repository was built from included a
stock/wallpaper-style image here (`wp1909426_4.jpg`) with no verifiable
license or attribution. It has been **intentionally excluded** from this
public repository — see [`THIRD-PARTY-NOTICES.md`](../THIRD-PARTY-NOTICES.md#4-bundled-image-asset--resourceswp1909426_4jpg)
for the full explanation.

Drop your own project images here, or let GuiBuilder's file picker copy them
in for you — just make sure you have the rights to redistribute anything you
commit to this folder.
